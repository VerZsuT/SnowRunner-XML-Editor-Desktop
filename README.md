# SnowRunner XML Editor Desktop

Программа позволяет редактировать XML файлы игры SnowRunner с помощью редактирования визуальной таблицы
параметров.

_Стек:_ **TypeScript**, **React**, **HTML5**, **SASS**, **Rust**, **Tauri**, **Vite**.

_Краткое описание:_ редактор распаковывает нужные файлы из _initial.pak_ во временную папку и работает с ними через UI. При сохранении изменения вносятся в архив.

_Функционал:_

- Редактирование параметров через UI.
- Импорт/экспорт/сброс.
- Фильтрация списка, добавление в избранное. Альтернативный вид списка.

## Установка

В релизах две версии:

- _Установщик_. Устанавливает программу в систему (.exe).
- _Архив_. Портативная версия программы (.zip).

Программа работает на Tauri (Rust) с версии 2.0.0. Нужны Windows 10 или 11 (x64) и WebView2: на Windows 11 он уже установлен, на Windows 10 установщик поставит его сам, если есть доступ в интернет.

### Где хранятся данные

- Установленная версия хранит настройки, бэкапы и временные папки в `%APPDATA%\SnowRunner XML Editor` и не требует прав администратора при запуске.
- Портативная версия хранит данные в папке `data` рядом с `.exe`, если рядом лежит маркер `portable.txt` (он входит в портативный архив). Без маркера данные пишутся в `%APPDATA%`.
- При смене режима хранения json-файлы копируются в новый каталог без перезаписи существующих; временные файлы и бэкапы не переносятся.

## Разработка

_Требуется NodeJS и Rust (stable)._

Установка зависимостей:

```cmd
npm i
```

Запуск приложения в режиме разработки:

```cmd
npm run tauri:dev
```

Сборка установщика:

```cmd
npm run tauri:build
```

Установщик NSIS появится в `src-tauri/target/release/bundle/nsis`.  
zustand хранит только состояние интерфейса; данные игры, документы и конфигурация живут в Rust-ядре.

Документация для разработчиков — [docs/README.md](docs/README.md).

Значения каталогов проекта:

```text
/src:               основные ресурсы программы.
   /images:          графические ресурсы.
      /icons             прочие картинки.
      /trailers          картинки прицепов.
      /trucks            картинки авто.
      favicon.ico        иконка программы.
   /renderer:        интерфейс (React).
      /api               команды ядра и сгенерированные типы.
      /components        общие компоненты.
      /pages             экраны: списки, редактор, настройка.
      /tests             тесты.
      app.tsx            корневой экран.
      entry.tsx          монтирование приложения.
      config.ts          конфигурация интерфейса.
   /utilities:
      /localization      локализация интерфейса.
         /locales           тексты языков: ru (эталон), en, de, ch.
      /strings           форматирование строк.
   global.d.ts
   tsconfig.json        основная TS конфигурация.
/src-tauri:           ядро на Rust.
   /crates/domain        XML, модели игры.
   /crates/storage       файлы, ZIP, атомарная запись.
   /crates/app           конфигурация, документы, моды, обновления.
   /src                  команды Tauri.
   tauri.conf.json       окно, сборка, установщик.
```
