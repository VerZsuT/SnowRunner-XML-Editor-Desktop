# Глоссарий

Термины проекта и SnowRunner. Для API-типов смотрите [bindings.ts](../src/api/bindings.ts).

## Игра и файлы

| Термин | Значение |
|---|---|
| `initial.pak` | zip-архив с ресурсами игры; редактор распаковывает из него нужные файлы |
| `classes` | каталог XML-классов игры: траки, двигатели, коробки, подвески, колёса, аддоны |
| `_templates` | шаблоны значений атрибутов; `Include` подключает общий файл шаблонов |
| `_dlc` | каталог DLC; файлы DLC имеют приоритет над основной игрой |
| `[media]`, `[strings]` | служебные каталоги архива с ресурсами и строками |
| DLC | загружаемое дополнение игры |
| Мод | `.pak`-файл с `classes`, подключаемый пользователем |
| `edited` | пустой файл-маркер в корне архива: архив пересобран редактором |
| `mainTemp` | каталог распакованных файлов основной игры/DLC |
| `modsTemp` | каталог распакованных файлов модов |

## Предметная модель

| Термин | Значение |
|---|---|
| Трак / прицеп | корневой элемент `Truck`; отличается атрибутом `Type` |
| `TruckData` | параметры трака: управляемость, топливо, колёса, лебёдка |
| `GameData` | цена, разблокировка, UI, сокеты аддонов |
| Аддон | устанавливаемый элемент (`TruckAddon`), например кран или кузов |
| Сокет | место установки аддона; список имён в `AddonSockets` |
| `AddonsShift` | сдвиг/блокировка аддонов при установке |
| `UiName` | ключ перевода названия в игровых строках |
| `CompatibleWheels` | наборы колёс, совместимые с траком |
| Физическая модель | `PhysicsModel`/`PhysicsBody`: масса и центр масс |

## Редактор

| Термин | Значение |
|---|---|
| Документ | открытый XML-файл в памяти Rust; имеет `docId` |
| `revision` | версия документа; растёт при каждой мутации |
| `dirty` | есть несохранённые правки |
| `docId` | идентификатор открытого документа (`doc-1`, `doc-2`, ...) |
| `selector` | стабильный путь узла: `/Truck/TruckData`, `/EngineVariants/Engine[0]` |
| `Field<T>` | значение + дефолт + дескриптор |
| `AttrDescriptor` | метаданные поля: имя, путь, тип, лимит, шаг, опции, ключи локализации |
| Мутация | `set_attr`, `set_text`, `add_element`, `remove_element`, `move_element` |
| `.epf` | JSON-файл обмена параметрами траков (версия 3.0) |

## Технические

| Термин | Значение |
|---|---|
| Tauri | платформа десктопного приложения: Rust-ядро + webview |
| Команда | функция Rust, вызываемая из webview через `invoke` |
| DTO | структура передачи данных между Rust и TS |
| `bindings.ts` | сгенерированные команды, события и типы |
| `typegen` | генератор `bindings.ts` из Rust |
| Specta | библиотека генерации TS-типов и описания команд |
| Watcher | наблюдение `notify` за файлами открытых документов; событие `documents-changed` |
| `AppState` | общее состояние Rust: пути, конфигурация, документы, списки, моды |
| zustand | хранилище UI-состояния (конфигурация интерфейса) |
| Атомарная запись | временный файл → `fsync` → переименование |
| Lossless XML | сохранение исходной разметки при чтении; `to_xml()` байт-в-байт |
| Нормализация | форматирование XML при сохранении (2 пробела, CRLF) |
| `defaults.json.gz` | сжатая выгрузка значений параметров 1.4.0 для сброса полей |
| Фикстура | локальный `initialpak/` для интеграционных тестов; не в git |
| jsdom | окружение Vitest для компонентов |
