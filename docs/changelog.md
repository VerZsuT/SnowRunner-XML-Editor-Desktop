# Changelog

Краткая история логических изменений начиная с перехода на React.
Версии 1.x (Vue + Electron) здесь не описываются; это другая линия развития.
Даты — по тегам и коммитам репозитория.

## 2.0.0 — 2026-11-21…22

**Переход на React.** Интерфейс переписан с Vue 3 + ant-design-vue на React 19 + antd 6.
Тесты переведены на Testing Library; состояние интерфейса — zustand.

**Новая платформа.** Electron, `emr-bridge` и `valtio` заменены на Tauri v2 и Rust-ядро.
WinRAR больше не используется: архив читается и пересобирается собственным zip-слоем.
Установщик NSIS ставится в профиль пользователя; портативная сборка — `.zip` с `portable.txt`.
Требования: Windows 10/11 x64 и WebView2.

**Ответственность слоёв.** Игровые данные, XML и файлы принадлежат Rust; webview получает DTO
и отправляет команды. Типы TypeScript генерируются из Rust и проверяются в CI.

**Редактор.** Поддержаны траки, прицепы, двигатели, коробки передач, подвески, лебёдки,
колёса и аддоны. Добавлены физическая модель, сокеты аддонов, краны, прицепы,
«Банан бандита», импорт/экспорт `.epf`, работа с DLC и модами.

**Данные игры.** Списки траков и прицепов, фильтры, избранное, изменённые файлы,
игровые переводы из `strings_*.str`, настройка путей, распаковка, бэкап, проверка
и восстановление архива.

**Интерфейс.** Языки RU/EN/DE/CH, локаль antd под язык, уведомление об обновлении,
окно «Что нового», экран настройки, портативный режим.

**Поставка.** CI проверяет типы, линт, тесты, Rust, clippy и fmt; на тег собираются
установщик и портативный архив. Автообновление скачивает файлы из GitHub Releases
по `version-info.json`.

## После 2.0.0 — ветка `dev`, версия не поднята

* Локализация вынесена в отдельные файлы языков; язык применяется до загрузки интерфейса,
  смена языка перезагружает окно.
* Rust-тесты вынесены из модулей в отдельные файлы; поведение не менялось.
* Добавлен комплект документации для разработчиков (`docs/`); сайт GitHub Pages
  перенесён в `site/`.
* Первый запуск: экран первоначальной настройки (язык программы → игровые данные) вместо
  пустого списка; язык подставляется по локали системы; окно 800×600 логических пикселей (около 1000×800 с заголовком при масштабе 125%)
  по умолчанию и в качестве минимального размера.
* Верхнее меню как в 1.4.0 (Файл, Бэкап, Настройки, Помощь) над всеми экранами; язык переключается
  тем же выбором, что и в первоначальной настройке — меню, экран настройки, окно «Что нового»
  и шаг с языком обновляются без перезагрузки.
  Заголовок окна содержит версию, шапка страницы приведена к размерам 1.4.0.
* В меню «Настройки» добавлены «Сбросить» (первоначальное состояние и перезапуск) и
  «Удалить программу» (запуск `uninstall.exe`) — как в 1.4.0.
* Настройки снова модальное окно, как в 1.4.0: язык программы и переключатели «Обновлять программу»,
  «Редактировать модификации», «Продвинутый режим», «Портативный режим»; «Оптимизировать распаковку»
  не переносится. Пути, файлы игры и моды переехали на экран «Файл → Данные игры».
* Списки вернулись к виду 1.4.0: карточки с обложками и режим строк с миниатюрами, переключение вида,
  сворачивание фильтров, подсветка совпадения поиска, значки избранного и изменённого файла.
* Правый клик по файлу в списке открывает меню «избранное / экспорт / импорт / сброс»;
  меню WebView2 в окне больше не появляется. Меню рендерится порталом в `body`,
  поэтому фильтр hover у строки не обрезает его и не сдвигает при движении курсора.
* Шапка и меню приведены к 1.4.0: высота меню 30px, заголовок центрируется по окну,
  кнопки фильтра и вида — белые круглые 32px с иконками 25px; фильтры снова `size="large"`.
* Список получил фон 1.4.0 (`#e7ebf0`), неподвижную ширину карточек при скрытой полосе
  прокрутки, skeleton вместо крутилки, анимацию панели фильтров, размытые миниатюры строк
  и hover без мигания `box-shadow`.
* Списки кэшируются по категории и не запрашиваются заново при переключении фильтров
  и возврате из редактора; сам список не размонтируется, поэтому фильтры, вид и скролл
  остаются на месте.
* У кнопок фильтра и вида в шапке убрана белая рамка, которая появлялась на hover из-за
  правила Ant Design; в источнике «Моды» добавлена кнопка «Изменить» с окном управления модами.
* Полоса прокрутки списка повторяет 1.4.0: ширина 4px, серый ползунок и тёмный трек.
* В окне модов появился список `.pak`, найденных по стандартному пути SnowRunner; моды
  выбираются флажками и добавляются пакетно, ручной выбор `.pak` сохранён.
* Сохранение в редакторе сразу пересобирает исходный `.pak` (основной игры или мода);
  импорт `.epf` тоже применяется к архиву без отдельного «Обновить архив».
* Таблица редактора приведена к 1.4.0: верхнеуровневые группы с иконками и заголовками 45px
  открываются по одной, строки параметров имеют фиксированные контролы 150px, на широком окне —
  две колонки; у прицепа отдельная таблица «Полезное содержимое / Масса / Прочее».
  Правый клик по заголовку сбрасывает параметры группы, как в 1.4.0.
* Редактор доделан по списку замечаний к 1.4.0: анимация аккордеона и стрелки 1.4.0,
  автосворачивание на каждом уровне вложенности, скругления и рамка раскрытой шапки;
  select подстраивается под содержимое и выравнивает значения влево; подсказки ограничений
  показываются и на поле ввода; неверное число возвращает прежнее значение.
* В продвинутом режиме связанные файлы показывают кликабельное имя, открывающее файл
  во внешнем редакторе; Rust-watcher перечитывает изменённые извне модели. Группы
  двигателей, коробок, подвесок, лебёдок и колёс называются игровыми названиями и получают
  параметр «Название» с кодом элемента.
* «Подвеска» вернула смещение центра масс, отдельная «Физическая модель» и «Сокеты аддонов»
  убраны. Колёса перестроены: «Дополнительно» и «Доступные размеры колёс» идут после файлов,
  у наборов размеров подписи — имена файлов.
* Шапка редактора получила меню 1.4.0 (сброс, экспорт/импорт, «Файлы» только в продвинутом
  режиме) и красную звёздочку несохранённых правок; отступы шапки симметричны.
* Аддоны: загрузка по центру, фильтр по имени, правка запасов без кнопки «Создать TruckData»,
  открытие файла во внешнем редакторе. Краны и прицепы оформлены карточками в две колонки,
  как в 1.4.0.
* Аккордеон больше не «дёргается»: тело клипует содержимое на всё время анимации,
  подписи полей выровнены с заголовками, имя файла слито с первой группой, а снизу
  скругляется только последняя группа файла. У несохранённых правок звезда стоит
  в углу иконки сохранения.
* Цветовые зоны меняют рамку поля; логическое значение по умолчанию показывается словами.
  У колёс убраны масса и скейл массы, у аддонов — фильтр «Установленные» и плашка статуса.
* «Сбросить» применяет значения из выгрузки 1.4.0 (`defaults.json.gz`, 945 файлов)
  к полям документа в памяти и не сохраняет архив автоматически.

## Что считать записью

Запись описывает изменение поведения или контракта, а не конкретные файлы и функции.
Внутренние рефакторинги без изменения поведения в историю не попадают.
