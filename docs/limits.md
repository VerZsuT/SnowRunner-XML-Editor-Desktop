# Известные ограничения

Документ фиксирует принятые компромиссы и места, где поведение может удивить.
Это не список багов; для планов см. [roadmap.md](roadmap.md).

## Платформа

| Ограничение | Следствие |
|---|---|
| Только Windows 10/11 x64 | Нет сборок под Linux, macOS, ARM и 32-битную Windows |
| Нужен WebView2 | Без него окно не запустится; установщик может поставить компонент при наличии интернета |
| Одно окно `general` | Нет многооконного режима и вкладок между экранами |
| Нет явной блокировки второго экземпляра | Два запущенных редактора могут писать одни файлы |
| CSP: `default-src 'self'` | Удалённые скрипты/стили не загружаются; картинки — только свои |

## Архив и файлы

| Ограничение | Следствие |
|---|---|
| Поддерживается только zip без zip64 | Архив > 4 ГиБ на запись или > 65 535 записей отвергается до записи |
| Нет data descriptor | Архивы с этим флагом не читаются |
| Нет шифрования и других методов сжатия | Только `stored` и `deflate` |
| Один формат `initial.pak` | Неизвестная структура игры даёт ошибку; fallback на старую версию нет |
| `unpack` не очищает `mainTemp` | Старые файлы могут остаться и попасть в пересобранный архив |
| Обновление архива всегда пересобирает его целиком | Долго на большом архиве; прогресса и отмены нет |
| `edited` добавляется всегда | Даже при отсутствии изменений архив получает маркер |
| Автобэкапа при обновлении нет | Бэкап — отдельное действие; распаковка из пустого списка тоже без бэкапа |
| `restore_backup` использует только `backups/initial.pak` | Датированные бэкапы восстанавливаются вручную |
| Нет watcher внешних изменений | Правка файла вне редактора не обнаруживается; `sizes.json` не ведётся |
| Операции с архивом синхронны для UI | Кнопки ждут завершения; прогресс-колбэки в командах не используются |

## XML и модель

| Ограничение | Следствие |
|---|---|
| Сохранение всегда форматирует XML | 2 пробела, CRLF, самозакрытие; побайтовый diff может быть большим |
| Модель знает не все элементы/атрибуты | Неизвестные узлы сохраняются в дереве, но не редактируются через UI |
| Нет валидации по схеме игры | Ошибку структуры пользователь увидит только в игре |
| Пустой атрибут считается отсутствующим | UI показывает значение по умолчанию; пустая строка неотличима от отсутствия |
| Неизвестные именованные сущности не раскрываются | DTD не загружается и не валидируется |
| Одна кодировка на документ | Смешанные кодировки/битый BOM дают ошибку |
| Координаты и числа ограничены `f64` | NaN/бесконечность не проходят через JSON; в TS координаты могут быть `null` |

## Документы и состояние

| Ограничение | Следствие |
|---|---|
| Нет автосохранения | Закрытие приложения с `dirty`-документами теряет правки |
| `revision` защищает только внутри приложения | Внешнее изменение файла будет перезаписано при сохранении |
| Один писатель на документ | Параллельные сессии в одном окне сериализуются; между экземплярами — нет |
| `open_document` идемпотентен по точному пути | Разные написания пути могут дать разные документы |
| `open_at` ограничен данными игры/DLC/мода | Открыть произвольный XML нельзя |
| Нет фонового прогресса | Долгие `list_trucks`, `verify`, `update` блокируют интерфейс |

## Интерфейс

| Ограничение | Следствие |
|---|---|
| Язык фиксируется при старте | Смена языка перезагружает окно; рантайм-перевода нет |
| Часть подписей редактора — русские строки | В EN/DE/CH они остаются русскими |
| `advancedMode` хранится, но не влияет на UI | Переключатель есть, поведения за ним нет |
| `optimizeUnpack` хранится, но не влияет | Распаковка всегда использует `optimized`-список |
| Списки фильтруются в памяти | Большое число модов/файлов замедляет экран |
| Нет E2E и визуальных тестов | Регрессии ловятся unit/integration-тестами и вручную |
| Нет отмены длительных операций | Пользователь ждёт завершения |

## Моды

| Ограничение | Следствие |
|---|---|
| Мод обязан содержать `classes` | Иначе добавление отклоняется |
| Переводы мода — только `texts/strings_<язык>.str` | Другие форматы не читаются |
| `sync_mods` сравнивает только размер | Изменение с тем же размером не пересоберётся |
| `remove_mod` не удаляет файлы | `.pak` и `modsTemp/<мод>` остаются на диске |
| Имя мода санитайзится и переводится в нижний регистр | Возможны коллизии имён; запись перезаписывается |

## Обновления и релиз

| Ограничение | Следствие |
|---|---|
| `site/version-info.json` сейчас содержит `1.4.0` | Пока не поднято до 2.0.0, автообновление не предложит 2.0.0 |
| Портативные 1.4.0 ждут `.rar` | 2.0.0 поставляется как `.zip`; таким пользователям нужен ручной переход |
| Нет проверки подписи/хеша | Доверие только HTTPS и GitHub Releases |
| Нет delta-обновлений | Скачивается полный установщик/архив |
| Проверка версии — один JSON | Ошибка/404 на сайте отключает предложение обновления |
| Релиз публикуется вручную | Файлы должны быть загружены до обновления `version-info.json` |

## Тесты и CI

| Ограничение | Следствие |
|---|---|
| `initialpak/` не в git | Интеграционные тесты на фикстуре пропускаются, если каталога нет |
| CI не запускает игру | Реальная совместимость архива проверяется вручную |
| Нет порога покрытия | Покрытие не является блокирующим |
| Нет тестов на Windows 10 в CI | Проверка старых ОС — ручная |
