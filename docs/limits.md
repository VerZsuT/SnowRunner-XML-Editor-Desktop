# Известные ограничения

Документ фиксирует принятые компромиссы и места, где поведение может удивить.
Это не список багов; для планов см. [roadmap.md](roadmap.md).

## Платформа

| Ограничение | Следствие |
|---|---|
| Только Windows 10/11 x64 | Нет сборок под Linux, macOS, ARM и 32-битную Windows |
| Нужен WebView2 | Без него окно не запустится; установщик может поставить компонент при наличии интернета |
| Одно окно `general` | Нет многооконного режима и вкладок между экранами |
| «Удалить программу» есть только у установленной сборки | Портативная версия получает ошибку «деинсталлятор не найден» |
| Нет явной блокировки второго экземпляра | Два запущенных редактора могут писать одни файлы |
| CSP: `default-src 'self'` | Удалённые скрипты/стили не загружаются; картинки — только свои |

## Архив и файлы

| Ограничение | Следствие |
|---|---|
| Поддерживается только zip без zip64 | Архив > 4 ГиБ на запись или > 65 535 записей отвергается до записи |
| Нет data descriptor при пересборке | Архив с этим флагом читается, но любая пересборка отклоняется до записи |
| Нет шифрования и других методов сжатия | Только `stored` и `deflate` |
| Запись больше 512 МиБ не читается в память | Защита от OOM; такие записи в списках распаковки игры не встречаются |
| Один формат `initial.pak` | Неизвестная структура игры даёт ошибку; fallback на старую версию нет |
| `unpack` очищает `mainTemp` только после успешной распаковки | Прежний каталог удаляется или уходит в `previous_initial`; при сбое staging удаляется, старые файлы целы |
| Отпечаток архива не криптографический | Сравниваются размер, mtime и CRC32 central directory: подмена содержимого при том же CRC и восстановленном времени не обнаружится |
| Окно TOCTOU между проверкой и пересборкой | Архив может замениться после `require_unchanged`, но до `zip::update`; защита на уровне записи в план не входит |
| `previous_initial` занимает место как распакованный архив | Хранится одно поколение: копия заменяется следующим перечитыванием; отказ от восстановления её не удаляет (удаление — отдельной кнопкой) |
| Сбой записи `archive.json` переводит состояние в `unknown` | Пересборка выполнена, но запись запрещена до повторной распаковки |
| Второй экземпляр программы не поддерживается | Его staging-каталоги `mainTemp.new-*` удаляются при распаковке |
| Отпечатков модовых `.pak` нет | Мод пересобирается без проверки; смена основного архива модовые документы не блокирует |
| Обновление архива всегда пересобирает его целиком | Долго на большом архиве; прогресса и отмены нет. Сохранение документа обновляет архив сразу, поэтому каждое сохранение ждёт полной пересборки |
| Изменённые и новые файлы при пересборке держатся в памяти | Предел — размер самих файлов; записи архива копируются потоково, но не тронутые файлы в память не читаются |
| Маркер `edited` больше не пишется | Архивы 2.0.0 его не получают; старый маркер остаётся в архиве (zip-слой не удаляет записи) и читается только как диагностика `markerPresent` |
| 1.4.0 после 2.0.0 может показать ложное «обновление» | 1.4.0 проверяет непустой `edited.json` и отсутствие маркера; после пересборки архива в 2.0.0 это ожидаемо и не мешает 2.0.0 |
| Автобэкапа при обновлении нет | Бэкап — отдельное действие; распаковка из пустого состояния списков тоже без бэкапа |
| `restore_backup` использует только `backups/initial.pak` | Датированные бэкапы восстанавливаются вручную |
| Watcher следит только за открытыми документами | Правка закрытого файла не замечается; `sizes.json` не ведётся |
| У большинства операций с архивом нет прогресса и отмены | Команды уходят в `spawn_blocking`, но кнопки ждут завершения: процент и отмена есть только у восстановления параметров |

## Восстановление после обновления игры

| Ограничение | Следствие |
|---|---|
| Восстанавливаются только поля, сохранённые в журнал | Поля, которых нет в журнале, не читаются и не меняются: это защита от затирания изменений игры |
| 1.4.0 и ранняя 2.0.0 не имеют истории полей | Для траков включается режим «нет истории» — грубое подтверждение по файлу; связанные документы (двигатели, коробки, подвески, лебёдки, колёса) и аддоны без истории не восстанавливаются |
| Действия (краны, прицепы, «Банан бандита») без 3-way | Только добавляются, если их нет в новом файле; удаление действия игрой может остаться |
| Перемещённый или удалённый игрой файл пропускается | Цель ищется по точному пути записи `archiveName`; одноимённые файлы в других каталогах не перебираются |
| Хранится одно поколение `previous_initial` | Следующее перечитывание архива заменяет копию; хранения нескольких поколений нет, окна об этом предупреждают |
| Восстановление запускается вручную или из окна после перечитывания | Автоматического переноса при старте нет; из меню при несохранённых документах запуск отклоняется |
| Журнал ведётся с 2.0.0 | Его потеря или сброс к первоначальному состоянию обнуляет историю полей; для траков останется только грубый режим «нет истории» |
| Правка после обновления сдвигает базу | Если пользователь правит поле, отложив восстановление, база для него становится значением новой версии игры, а старая правка заменяется |
| Списки полей поддерживаются вручную | Новое поле редактора без правила в `sxmle-domain/src/game/editable.rs` не попадёт в журнал и восстановление |
| Пересборка архива — один раз после применения | Долго на большом архиве; прогресс по файлам, затем «Сборка архива…» |

## XML и модель

| Ограничение | Следствие |
|---|---|
| Сохранение всегда форматирует XML | 2 пробела, CRLF, самозакрытие; побайтовый diff может быть большим |
| Модель знает не все элементы/атрибуты | Неизвестные узлы сохраняются в дереве, но не редактируются через UI |
| Нет валидации по схеме игры | Ошибку структуры пользователь увидит только в игре |
| Пустой атрибут считается отсутствующим | UI показывает значение по умолчанию; пустая строка неотличима от отсутствия |
| Неизвестные именованные сущности не раскрываются | DTD не загружается и не валидируется |
| Одна кодировка на документ | Смешанные кодировки/битый BOM дают ошибку |
| Глубина XML ограничена 512 уровнями | Более глубокая вложенность отвергается при разборе |
| `Include` шаблонов — только имя файла | Путь, `..` и `:` в `_templates` не подключаются |
| Координаты и числа ограничены `f64` | NaN/бесконечность не проходят через JSON; в TS координаты могут быть `null` |

## Документы и состояние

| Ограничение | Следствие |
|---|---|
| Нет автосохранения | Закрытие приложения с `dirty`-документами теряет правки |
| `revision` защищает только внутри приложения | Watcher перечитывает изменённый извне файл и отбрасывает несохранённые правки документа; между экземплярами программы защиты нет |
| Один писатель на документ | Параллельные сессии в одном окне сериализуются; между экземплярами — нет |
| `open_document` идемпотентен по точному пути | Разные написания пути могут дать разные документы |
| `open_at` ограничен данными игры/DLC/мода | Открыть произвольный XML нельзя |

## Интерфейс

| Ограничение | Следствие |
|---|---|
| Язык применяется при старте | Меню, списки, настройки и «Что нового» меняются сразу, остальной интерфейс — после перезагрузки окна |
| Часть подписей редактора — русские строки | В EN/DE/CH они остаются русскими |
| Значения по умолчанию — выгрузка 1.4.0 | Сброс не учитывает версию игры, DLC и моды: значения могут отличаться от актуальных |
| Списки фильтруются в памяти | Большое число модов/файлов замедляет экран |
| Нет E2E и визуальных тестов | Регрессии ловятся unit/integration-тестами и вручную |
| Нет отмены длительных операций | Пользователь ждёт завершения; `list_trucks` и `list_trailers` выполняются синхронной командой |

## Моды

| Ограничение | Следствие |
|---|---|
| Мод обязан содержать `classes` | Иначе добавление отклоняется |
| Переводы мода — только `texts/strings_<язык>.str` | Другие форматы не читаются |
| `sync_mods` сравнивает только размер | Изменение с тем же размером не пересоберётся |
| `remove_mod` не удаляет файлы | `.pak` и `modsTemp/<мод>` остаются на диске |
| Имя мода санитайзится и переводится в нижний регистр | Возможны коллизии имён; запись перезаписывается |

## Обновления и релиз

| Ограничение | Следствие |
|---|---|
| `site/version-info.json` сейчас содержит `1.4.0` | Пока не поднято до 2.0.0, автообновление не предложит 2.0.0 |
| Портативные 1.4.0 ждут `.rar` | 2.0.0 поставляется как `.zip`; таким пользователям нужен ручной переход |
| Нет проверки подписи/хеша | Доверие только HTTPS и GitHub Releases |
| Нет delta-обновлений | Скачивается полный установщик/архив |
| Проверка версии — один JSON | Ошибка/404 на сайте отключает предложение обновления |
| Релиз публикуется вручную | Файлы должны быть загружены до обновления `version-info.json` |

## Тесты и CI

| Ограничение | Следствие |
|---|---|
| `initialpak/` не в git | Интеграционные тесты на фикстуре пропускаются, если каталога нет |
| CI не запускает игру | Реальная совместимость архива проверяется вручную |
| Нет порога покрытия | Покрытие не является блокирующим |
| Нет тестов на Windows 10 в CI | Проверка старых ОС — ручная |
